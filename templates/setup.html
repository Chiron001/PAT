3
Save Configuration
Persist your settings so the app always connects to Supabase
Saves DATABASE_URL and ADMIN_PASSWORD to a .env file in the project folder. Restart the server after saving.
On Vercel, environment variables must be set in the dashboard — the server cannot write files. Follow these steps:
  1. Go to your Vercel project dashboard
  2. Click Settings → Environment Variables
  3. Add the following variables:
Variable 1
DATABASE_URL=postgresql://postgres:[password]@db.[ref].supabase.co:5432/postgres
Variable 2 (recommended)
ADMIN_PASSWORD=your-secure-password-here
Variable 3 (recommended)
SECRET_KEY=your-long-random-secret-key
After adding environment variables, click Redeploy in Vercel for them to take effect.
